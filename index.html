Frequently Asked Questions

How does the location feature work? +
StayNest requests your browser's location permission. Once permission is granted, the website calculates the straight-line distance between your location and listed properties.
Can I search different cities? +
Yes. You can filter properties by Delhi, Patna, Mumbai, Bangalore, Phagwara and Jalandhar.
Can owners list properties? +
Yes. In a production version, property owners can submit their PGs, hostels and flats for verification.
Is the distance driving distance? +
No. The current prototype calculates straight-line geographical distance. A routing API would be required for actual road distance.
